# Cube Recall

Cube Recall is a local-first, Anki-style study tool for learning Rubik’s Cube algorithms and recognition.

## Included decks

- OLL — 57 cases
- PLL — 21 cases
- PLL Recognition — 21 cases
- F2L, one-handed, and blindfold practice decks

The study flow keeps setup moves visible, supports timed execution practice, reveals algorithms on demand, and schedules reviews with a small local spaced-repetition scheduler. Progress, review intervals, and best times are stored in this browser on this device. There are no accounts, server-side profiles, or telemetry.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
